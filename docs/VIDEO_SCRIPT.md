# ClaimVoyant — Video Recording Script

This script helps you present the ClaimVoyant solution clearly in under 5 minutes for judges.

- **Scene 1: Introduction (30 seconds)**  
  Introduce the core problem: Filing automobile claims today takes extensive phone calls and paperwork. Show the ClaimVoyant Editorial welcome page and click "Start Claim Conversation."

- **Scene 2: Verbal Scenario Descriptors (90 seconds)**  
  Type or speak into the microphone. Mention insurance carrier details (i.e. *"My insurer is SafeDrive and my policy matches POL-9999"*). Show prompt results updating in real-time, demonstrating live dialog comprehension.

- **Scene 3: Artifact OCR cards (40 seconds)**  
  Progress to Step 2. Click simulated files (*Frontal Crash* / *Liability document cards*) to fast-track visual feature extraction. Show simulated Gemini analysis mapping values.

- **Scene 4: Dynamic Ledger Validation (60 seconds)**  
  Review pre-populated fields. Click submit. Show Server-Sent Events executing progressive validation steps (fraud check, ledger clearance, XML submission, MIME adjustor logs) accompanied by agent verbal announcements.
